## 📞 Client Interaction Scripts (Before / During / After)

### 🟢 Before First Contact — "The Silent Credibility Kit"

> Send this as a Loom video or a simple message on Upwork / Fiverr / LinkedIn:

> *"Hi [Client Name], before we jump on a call, here's my live portfolio: [link to your GitHub Pages]. Also, here are three live apps I've built and deployed: [AI Digital Card], [AI Training Platform], and my GitHub with 200+ repos. This is my 'second brain' — everything is documented. When would you have 20 min for a quick discovery call?"*

### 🟡 Discovery Call — "The Confidence Script"

> *"I don't just write code — I build systems that make you money or save you time. My stack is FastAPI, Python, Selenium, and React. I deploy on Render / Vercel / your own server. Tell me about the #1 problem you want solved this month."*

**Then ask these three magic questions:**
1. *"What happens if this project is never built?"* (uncovers pain → higher budget)
2. *"What does 'done' look like for you?"* (scoping)
3. *"Do you have a specific budget range in mind, or should I propose two options — basic and advanced?"* (qualifies price)

### 🔴 Proposal Follow-Up — "The Value Reminder"

> *"Attached: 1-page proposal with milestones, timeline, and fixed price. You also get my 'Second Brain Guarantee': full source code, documentation, and 1 week of free support after launch. I've already built similar systems — see [AffiliateMath.xyz] and my GitHub. Ready to start when you are."*
